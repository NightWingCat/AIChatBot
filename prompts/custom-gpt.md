# ChatGPT GPTs(맞춤형 GPT)로 바로 쓰기

웹앱 없이 ChatGPT 유료 플랜의 **GPT 만들기**에 붙여 넣어 바로 테스트할 수 있습니다.

| 항목 | 값 |
|---|---|
| 이름 | 손프라 — 내 책상 위 프라모델 숍 |
| 설명 | 공간 걱정 없이 웹에서 프라모델을 조립해 데스크톱에 진열하는 숍. 만들고 싶은 디자인을 보여 주시면 런너 시안과 조립용 설계 JSON을 뽑아 드려요. 괴작 조립 환영. |
| 지침(Instructions) | [`system-prompt.md`](./system-prompt.md) 전체를 복사해 붙여 넣기 |
| 기능 | ✅ 이미지 생성 · ✅ 코드 인터프리터 및 데이터 분석(JSON 파일 저장용, 선택) · ⬜ 웹 검색(끔) |

## 대화 스타터
- 🎨 만들고 싶은 디자인이 있어요
- 🐾 반려동물을 키트로 만들고 싶어요
- 🤪 괴작 조립하러 왔어요
- 👀 그냥 구경 왔어요

## 테스트 체크리스트
1. 첫 메시지가 "어떻게 오셨어요?"로 방문 목적부터 묻는가 (사진부터 요구하지 않는지)
2. 흐린/잘린 사진 → 🛠️ 보완 필요 + 재업로드 체크리스트, 이미지·JSON 없음
3. 정면 전신 사진 → ✅ 합격 + 시안 이미지 1장 + ```json 블록 1개
4. JSON을 [`schema/handoff.schema.json`](../schema/handoff.schema.json)으로 검증 (`npm run validate -- 파일.json`)
5. "매운맛으로 바꿔줘" → 톤 변경, 피사체 비하는 없음
