# ☠ 지옥문의 사신

레트로 16비트 픽셀 감성의 **심리 추리 웹 게임**. 지옥문의 사신이 되어 망자의 현생 사건을 심문하고 **천국** 또는 **지옥**으로 보냅니다.

- 플레이: https://hellgate-reaper.vercel.app
- 단일 파일: [`public/index.html`](public/index.html) — 이 파일 하나만 브라우저로 열어도 바로 플레이됩니다.

## 게임 루프

한 화면(가로)에 **왼쪽 픽셀 스테이지 / 오른쪽 심문 채팅**만 둡니다.

1. **전령 까마귀**: 지옥문 왼쪽 나뭇가지의 까마귀가 하늘 위에 밝은 글씨로 망자와 **사인, 어떻게 죽었는지만** 말하듯 전합니다(항상 표시). 선악을 짐작할 내용은 심문으로만 드러납니다.
2. **심문**: 질문할 때마다 **모래시계**가 줄어듭니다(기본 5개).
   - **첫 질문은 고르기**: 망자마다 첫 질문은 핵심 단서 5개와 이어지는 보기 5개 중에서 고릅니다(스토리와 동떨어진 실마리 방지). 그다음부터 자유롭게 입력합니다.
   - **정곡 회복**: 망자가 지옥 갈까 두려워하는 화제(사건마다 정해진 키워드, 사실이든 오해든)를 추궁하면 **모래시계 +1** (화제마다 1번, 사건당 최대 2번).
   - **압박 단계**: 정곡을 찌를수록 망자가 동요해 **질문과 관련된** 속얘기를 더 털어놓습니다. 사건마다 핵심 단서는 **5개**이고, 단서는 관련 질문에서만 나옵니다(압박 0: 가끔 입을 다묾 / 압박 2: 질문이 걸친 단서 2개까지).
   - **거짓말과 저울**: 망자는 일부러 거짓말을 합니다(지옥행은 자주, 천국행은 남을 감싸거나 자책하려 가끔). 거짓말엔 단서가 드러나지 않습니다. 무대 우측 상단 **진실·거짓의 저울**이 답변마다 푸른 접시/초록 접시 쪽으로 기우는데, **어느 접시가 진실인지는 망자마다 무작위**로 바뀝니다. 얼버무리면 흔들리다 제자리로 돌아옵니다.
   - **진실의 시간**: 세 번째 질문은 진실의 시간. 무엇을 묻든(보기든 채팅이든) 망자는 진실만 답해야 하며, 이 답으로 저울의 어느 쪽이 진실인지 가늠할 수 있습니다.
   - **떠오른 질문**: 대답이 끝나면 바로, 마지막으로 드러난 단서에서 이어지는 질문 3개가 뜹니다(입력 중엔 숨김). 빗나간 질문 뒤엔 "이 방향은 아닌 것 같다"며 방향을 잡아 줍니다.
   - 대답이 끝나면 아직 드러나지 않은 정황을 겨냥한 질문 3개가 **바로** 떠오릅니다(입력 중엔 숨김).
   - 말풍선은 말하는 캐릭터의 **머리 위에서 커진 뒤** 글자가 찍히고, 드러난 단서는 망자 **좌/우 픽셀 태그(◆)**로 붙고, 그 단서를 흘린 망자에게 **점선**으로 이어집니다.
3. **판결**: [천국]/[지옥]. 45% 확률로 **최후의 변론!**(태세 전환·눈물 호소·말 바꾸기·반전 어필) — 5개 단서 중 **무작위 2개**를 끌어와 비틀고, 그 단서는 태그로 드러납니다 → 고수/번복.
4. **⚔ 처형!**: 게임 중 **딱 1번**. 천국도 지옥도 아닌, 이번 망자를 **무효**로 하고 다음 망자로 넘깁니다(연속 기록 유지).
5. **릴레이**: 맞히면 바로 다음 망자. 틀리면 **사신 처벌** → 게임 오버 결과 창(연속 심판 수, 칭호, 진실, 심판 기록, 공유 카드, 다시하기).

### 이변(이벤트)
- **동물 망자** (약 5번에 1번): 강아지·고양이·원숭이. `왈왈! (난 옆집 민수네 강아지 보리야!)`처럼 울음소리 + (번역).
- **함께 죽은 망자들**: 같은 사인으로 온 2~3명. 질문에 맞는 사람이 대답하고, 판결은 함께 받습니다.
- **외국인 망자**: 일본인·미국인은 원어로 말하고 괄호 안에 한국어 번역.

### 헷갈리게 만드는 겉모습
겉모습은 일부러 진실과 엇갈립니다. 기부왕 사장님은 가죽 라이더 재킷·피어싱·금목걸이에 껌을 씹고, 착한 할머니는 후드를 눌러쓰고 빵을 숨기며 눈을 굴리고, 가짜 의인은 메달을 반짝이며 엄지를 들고, 공익신고자는 선글라스에 돈 봉투를 꽂고 있습니다.

내장 사건 **39종** — 일반 18 · 외국인 6(일본어·영어) · 단체 6 · 동물 9 (천국 20 / 지옥 19). 사건마다 겉모습(look)이 달라 같은 망자처럼 보이지 않고, 브라우저에 본 사건을 기억해 **안 본 사건부터** 나옵니다. 사건 데이터는 `node scripts/validate-cases.cjs`로 검증합니다.

## 심문 엔진

| 엔진 | 조건 | 동작 |
|---|---|---|
| 내장 키워드·맥락 엔진 | 기본 | 질문에서 키워드를 찾아 가장 관련 있는 정황을 망자 대사로 돌려줌. 이미 나온 정황은 "아까 말했잖아요", 엉뚱한 질문엔 얼버무림 + "사신의 감" 힌트 |
| OpenAI (브라우저 키) | [⚙ 설정]에 API 키 입력 | 브라우저에서 OpenAI로 직접 호출(기본 `gpt-4o-mini`). 키는 우리 서버로 가지 않음. 저장 여부 선택 가능 |
| OpenAI (서버 키) | 서버 환경 변수 `OPENAI_API_KEY` | `/api/chat` 프록시로 호출, 키는 브라우저에 노출되지 않음. IP당 분당 요청 제한 |

AI 망자는 사건 비밀 파일(진실·정황)을 받고, 질문과 관련된 정황만 1~2개씩 흘리며, 지옥행 망자는 말실수·정정 같은 단서를 남기도록 프롬프트되어 있습니다. 실패하면 자동으로 내장 엔진으로 이어집니다.

## 실행

```bash
npm install
npm start          # http://localhost:3100
```

또는 `public/index.html`을 그냥 브라우저로 열어도 됩니다(서버 AI 프록시만 빠짐).

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (없음) | 서버 AI 심문용. 없으면 내장 엔진 / 브라우저 키 |
| `OPENAI_MODEL` | `gpt-4o-mini` | 서버 프록시 모델 |
| `RATE_LIMIT_PER_MIN` | `20` | IP당 분당 AI 요청 수 |
| `PORT` | `3100` | |

## 이미지 에셋

외부 이미지 없이도 Canvas 픽셀 아트(지옥문·화로·불티·사신·망자 6종·승리/처벌 연출)로 화면이 완성됩니다.
OpenAI 이미지 생성으로 만든 고디테일 16비트 픽셀 아트로 바꾸려면 [`docs/ASSETS.md`](docs/ASSETS.md)의 프롬프트로 뽑아 `public/assets/`에 넣고 `manifest.json`에 파일명을 적으세요.

## 구조

```
public/
  index.html            게임 전체 (픽셀 UI·말풍선·모래시계·사건·심문 엔진·연출·결과·공유·설정)
  assets/manifest.json  넣은 이미지 파일명 목록
docs/ASSETS.md          에셋 교체 가이드 + 이미지 생성 프롬프트
server.js               정적 호스팅 + 선택형 OpenAI 프록시 (/api/config, /api/chat)
api/index.js            Vercel 함수 진입점
```
