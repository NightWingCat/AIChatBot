# ☠ 지옥문의 사신

레트로 16비트 픽셀 감성의 **심리 추리 웹 게임**. 지옥문의 사신이 되어 망자의 현생 사건을 심문하고 **천국** 또는 **지옥**으로 보냅니다.

- 플레이: https://hellgate-reaper.vercel.app
- 단일 파일: [`public/index.html`](public/index.html) — 이 파일 하나만 브라우저로 열어도 바로 플레이됩니다.

## 게임 루프

1. **사건 브리핑**: 망자의 현생 사건이 짧게 제시됩니다. 줄거리엔 일부러 남긴 알쏭달쏭한 구멍(복선)이 있습니다.
2. **심문**: 추천 질문 칩을 누르거나 직접 질문합니다. 질문할 때마다 **모래시계**가 하나씩 줄어듭니다(기본 5개).
3. **판결**: 드러난 정황을 모아 언제든 [천국]/[지옥]을 선고합니다. 모래시계를 다 쓰면 판결만 남습니다.
4. **최후의 변론!**: 판결 순간 45% 확률로 망자가 태세 전환·눈물 호소·말 바꾸기·반전 어필을 합니다. 고수할지 번복할지 고르세요.
5. **결과**: 정답이면 천국의 빛기둥 / 지옥행 사슬 연출과 함께 승리, 오답이면 번개·사슬·낙인으로 **사신이 처벌**되고 게임 오버.
   결과 창에서 사건 요약, 판결, 정답 여부, 남은 모래시계, 사신 칭호, 진실을 보여 주고 **기록 복사·공유**와 **다시하기**를 제공합니다.

내장 사건 6종: 계곡의 휴대폰 · 기부왕 사장님 · 빵 도둑 할머니 · 불길 속 의인 · 회사를 판 배신자 · 10년 간병한 효자 (천국 3 / 지옥 3, 매 판 무작위)

## 심문 엔진

| 엔진 | 조건 | 동작 |
|---|---|---|
| 내장 키워드·맥락 엔진 | 기본 | 질문에서 키워드를 찾아 가장 관련 있는 정황을 망자 대사로 돌려줌. 이미 나온 정황은 "아까 말했잖아요", 엉뚱한 질문엔 얼버무림 + "사신의 감" 힌트 |
| OpenAI (브라우저 키) | [⚙ 설정]에 API 키 입력 | 브라우저에서 OpenAI로 직접 호출(기본 `gpt-4o-mini`). 키는 우리 서버로 가지 않음. 저장 여부 선택 가능 |
| OpenAI (서버 키) | 서버 환경 변수 `OPENAI_API_KEY` | `/api/chat` 프록시로 호출, 키는 브라우저에 노출되지 않음. IP당 분당 요청 제한 |

AI 망자는 사건 비밀 파일(진실·정황)을 받고, 질문과 관련된 정황만 1~2개씩 흘리며, 지옥행 망자는 말실수·정정 같은 단서를 남기도록 프롬프트되어 있습니다. 실패하면 자동으로 내장 엔진으로 이어집니다.

## 실행

```bash
npm install
npm start          # http://localhost:3100
```

또는 `public/index.html`을 그냥 브라우저로 열어도 됩니다(서버 AI 프록시만 빠짐).

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (없음) | 서버 AI 심문용. 없으면 내장 엔진 / 브라우저 키 |
| `OPENAI_MODEL` | `gpt-4o-mini` | 서버 프록시 모델 |
| `RATE_LIMIT_PER_MIN` | `20` | IP당 분당 AI 요청 수 |
| `PORT` | `3100` | |

## 이미지 에셋

외부 이미지 없이도 Canvas 픽셀 아트(지옥문·화로·불티·사신·망자 6종·승리/처벌 연출)로 화면이 완성됩니다.
OpenAI 이미지 생성으로 만든 고디테일 16비트 픽셀 아트로 바꾸려면 [`docs/ASSETS.md`](docs/ASSETS.md)의 프롬프트로 뽑아 `public/assets/`에 넣고 `manifest.json`에 파일명을 적으세요.

## 구조

```
public/
  index.html            게임 전체 (픽셀 UI·말풍선·모래시계·사건·심문 엔진·연출·결과·공유·설정)
  assets/manifest.json  넣은 이미지 파일명 목록
docs/ASSETS.md          에셋 교체 가이드 + 이미지 생성 프롬프트
server.js               정적 호스팅 + 선택형 OpenAI 프록시 (/api/config, /api/chat)
api/index.js            Vercel 함수 진입점
```
